# Rogue Raise

Notes, resources and shared material for [Rogue Raise](https://whiterabbitashland.com/rogue-raise), White Rabbit's recurring community build in Ashland, Oregon.

## What Is a Rogue Raise?

Each Raise takes on one civic challenge in the Rogue Valley. Over a focused, roughly 48-hour weekend, modeled on the old barn raise, local coders, designers and hands-on volunteers build practical tools for it. The weekend opens with stakeholder input, teams build in parallel, and they present to a panel of real users. Each project then gets a named owner tied to local stakeholders, so the work stays useful after the weekend.

Two commitments guide every Raise:

- **Humanity:** serve the people the community is trying to help.
- **Truth:** get as close as possible to what is real.
